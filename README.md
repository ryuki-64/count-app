# Count App v2

## 概要
JavaScriptの学習の一環として作成したカウントアプリの改良版です。  
基本的なカウント機能に加え、自動カウント機能や入力値のバリデーションを追加しました。

## 機能
- +1 / -1 / +10 によるカウント操作
- 0〜100の範囲制御
- 数値入力によるスタート値設定
- 上限・下限時のボタン無効化
- 自動カウント機能
- 自動カウント停止機能
- 範囲外入力時のセットボタン無効化

## 使用技術
- HTML
- CSS
- JavaScript

## 工夫した点
- 条件分岐を用いて数値の上限・下限を制御
- ボタンの有効 / 無効を切り替え、UIの使いやすさを意識
- setInterval を使用して自動カウント機能を実装
- 入力値チェックを追加し、範囲外入力を制御
